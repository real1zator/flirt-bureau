# Бюро флирта

Многостраничная витрина вымышленного аниме-ромкома. В ней есть интерактивная афиша, каталог с фильтрами, три профиля, галереи, сценарии со сравнительным прайсом и корзина. Избранное, обложки, корзина и брони хранятся в браузере. Иллюстрации созданы для демо. Для смены кадров и появления секций при прокрутке используются GSAP и ScrollTrigger.

## Запуск

Откройте `index.html`. Для проверки общего хранилища между страницами запускайте сайт как статический проект через HTTP.

```sh
python -m http.server 8080
```

Сайт откроется по адресу [http://localhost:8080](http://localhost:8080). Запускайте команду из каталога сайта.

## GitHub Pages

Загрузите файлы в корень репозитория и выберите **Settings → Pages → Deploy from a branch → main → /(root)**. Все ссылки между страницами относительные.
